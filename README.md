# AMANAH

One Ummah. One Network. Endless Good.

AMANAH is a free global Muslim community assistance platform.

## Mission
Connect Muslims worldwide through skills, knowledge,
volunteering and community support.

## Technology Stack
- Frontend: Next.js + React
- Backend: Python + Django REST Framework
- Database: PostgreSQL
- Styling: Tailwind CSS

## Business Model
- Completely free access
- No subscriptions
- No advertisements
- No compulsory payments

Under Development.
